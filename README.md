A small browser-based tool for drawing, saving, copying, importing, and exporting custom characters.

## Features

- Draw characters with a mouse, stylus, or touchscreen
- Import a photo of a handwritten character
- Clean up imported images
- Assign characters to normal Unicode or Private Use Area code points
- Save characters in the browser
- Copy characters as real text
- Paste characters into the editor
- Delete saved characters
- Export and import the character library
- Generate a TrueType font
- And when ur done, you can download the complete project as a ZIP file

## Run this locally 

1. Select the green code button
2. Select 'Download as .zip'
3. Open your devices file manager
4. open the .zip file (titled 'unicode-character-maker-main.zip')
5. open the folder
6. now you should see two files
7. open the .HTML file (it is titled 'index.html')
8. the application should open in your browser

(NOTE: ALWAYS REMEMBER TO SAVE YOUR FILES)
